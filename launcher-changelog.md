# История изменений лончера

Показывается в самом лончере при выходе новой версии. Последние версии сверху.

## 1.3.6 — 2026-08-29

- 🌐 Индикатор сервера мог показывать "офлайн", даже когда сервер реально работал — из-за изменения формата ответа `/serverinfo`. Починено.

## 1.3.5 — 2026-08-28

- 🛡️ Баг безопасности: если проверка обновления падала с ошибкой на середине (например, сервер отдал битый манифест), лончер показывал ошибку, но всё равно запускал игру с тем, что уже лежало на диске. Теперь падение проверки честно блокирует запуск.
- ⚡ Повторная проверка файлов стала намного быстрее — раньше каждый запуск лончера заново перехеширует все файлы, даже если ничего не менялось. Теперь пересчитываем хеш только для реально изменившихся файлов — на практике это в разы быстрее при обычном повторном запуске.
- 🌐 Починена ошибка "Все сервера недоступны" — зеркала были прописаны с неверным регистром пути.
- ⏱️ Лончер больше не "зависает" на пару минут при старте из-за старой проверки статуса сервера по UDP — теперь жёсткий таймаут 5 секунд.
- 🎮 GUI-версия лончера теперь тоже умеет запускать игру напрямую из Steam-копии (injector-режим), без дублирования ~1.5 ГБ файлов — раньше это работало только в консольной версии.
- 🚀 Параллельность закачек увеличена, докачка мелких файлов (модов) идёт заметно быстрее.
- 🔁 Повторные попытки при перегрузке сервера (429/503) теперь с exponential backoff, а не плоским повтором раз в секунду.
- Полная локализация интерфейса на 9 языков.
